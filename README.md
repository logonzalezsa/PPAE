# Programación para Análisis de Estructuras (PPAE)

**Universidad Nacional de Colombia – Sede Palmira**

Repositorio académico de la asignatura **Programación para Análisis de Estructuras**.

Este repositorio contiene material de apoyo, cuadernos de programación, ejemplos, retos y desarrollos realizados durante el curso.

## Propósito

Integrar los fundamentos del análisis estructural con herramientas de programación para la formulación, implementación y solución computacional de problemas de ingeniería estructural.

## Organización del repositorio

El contenido se organizará progresivamente de acuerdo con el desarrollo de la asignatura.
